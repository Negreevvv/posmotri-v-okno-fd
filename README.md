# Посмотри в окно

Проектная работа 2 спринта курса «Фронтенд-разработчик» в Яндекс Практикуме.

Приложение показывает видео из окон в разных городах. Можно найти видео по городу и времени суток, а по клику на карточку справа ролик открывается в большом окне.

## Что сделано

- лейаут страницы на флексбоксе
- видео и превью подогнаны под размеры через `object-fit`
- кастомные чекбоксы через псевдоэлемент `::after` и псевдокласс `:checked`
- состояния `:hover`, `:active` и `:focus-visible` у кнопок, полей и карточек
- обрезка длинных заголовков многоточием и описаний через `line-clamp`

## Технологии

- HTML5
- CSS3 (Flexbox, псевдоклассы и псевдоэлементы)
- Git
